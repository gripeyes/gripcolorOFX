# Experimental soft-guide bridge v0.2 (M8/M10)

This offline interface begins a Rendition–Pigment bridge without adding spatial processing to the core eight operators. It is diagnostic/reference assistance, not a production effect or physical layer reconstruction.

Input is finite scene-linear Rec.2020/D65 RGB as supplied, with alpha carried separately. Convert RGB to the suite's signed Oklab algebra. For fixed palette centers p_j and sigma > 0, define w_j(x) = exp(−||q(x)−p_j||²/(2 sigma²)) / sum_l exp(−||q(x)−p_l||²/(2 sigma²)). Log-sum-exp avoids underflow during normalization. Sigma is in absolute Oklab coordinate units; no 0–100 remapping is hidden. The memberships overlap smoothly and form a partition of unity. They are colour-only, not spatial or RGBXY memberships.

Convert centers back to RGB, b(x) = sum_j w_j(x) RGB(p_j), and retain r(x) = RGB(x)−b(x). Reconstruction is b+r. The residual is signed and unbounded; it must not be clipped or treated as a physical reflectance. Exact reconstruction is promised only within recorded float precision. Weight images alone are non-invertible. Coordinates outside the original colour model's valid domain have algebraic, not guaranteed perceptual meaning.

The NPZ contract contains `weights` (H×W×K float64), `centers_opponent` (K×3), `palette_rgb` (K×3), `signed_residual` (H×W×3) and `source_alpha` (H×W). The companion EXR contains float32 `weights.layer00` … `weights.layer07` plus unchanged A. These are data channels: no OCIO colour conversion, premultiplication or display transform may be applied to weights. The JSON records source frame, coordinates, sigma, layer count, reconstruction/partition errors and exposure sensitivity. Outputs preserve source pixel indexing; gradients and layer data exclude no source pixels. The current export is a full image array, not a host tiled/stride API.

A future consumer must version/freeze palette centers, coordinate adapter, sigma, layer identifiers, reference gamut and residual convention. Source hashes/provenance accompany this experiment; it is not yet a saved-project migration schema. Refitting centers independently each frame can reorder/flicker layers and is forbidden as an implicit temporal policy. Motion/lighting/scene changes need explicit consumer decisions. Absolute Oklab membership changes with exposure: tests at ±2 stops quantify this; no exposure equivariance is claimed.

A future Pigment consumer owns spatial filtering, edge-aware operations, local contrast and compositing. It must declare whether guides come from pre- or post-Rendition RGB, how frozen guides survive exposure changes, how alpha/zero-alpha RGB are handled, and whether it transports or preserves the residual. Current acceptance is only guide continuity, normalized weights and reconstruction of original RGB; edited pigment layers have no asserted inverse, neutral preservation, material realism or automatic artist benefit.

Experimental tests demonstrate near-double-precision reconstruction on three approved frames and signed/HDR stimuli, plus a second-content frozen palette test. They do not implement Reinhard/Fattal/WLS/local-Laplacian processing, hull optimization, a physical pigment model or a finished Pigment node. Those future spatial operations remain separate.
